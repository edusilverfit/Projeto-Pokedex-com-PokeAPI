# Projeto-Pokedex-com-PokeAPI

### Projeto de uma Pokedex consumindo a PokeAPI, construída com HTML5, CSS3, JavaScript e Node.js. Mostra listagem paginada, busca por nome/ID, visualização de detalhes com sprites oficiais e tratamento básico de cache no servidor.
